# كازينو الألعاب

لعبة ويب عربية RTL لحظية: حكيم + ٣ لاعبين، جرس وكروت حمراء/صفراء، ٣ Power-Ups حصرية، و٣ أوضاع: الجرس، أتوبيس/أكتر كلمات، ورويال رامبل. قابلة للتثبيت كـ PWA.

## التشغيل محليًا

```bash
pnpm install
pnpm --filter @casino/server dev
pnpm --filter @casino/web dev
```

التحقق:

```bash
curl http://localhost:3000/api/health
```

## تشغيل الأونلاين من غير أي تسجيل (لينك مؤقت من جهازك)

لو مش عايز تعمل حساب على أي منصة: السكريبت ده بيشغّل السيرفر محليًا، يفتح لينك عام مؤقت عبر Cloudflare (بدون حساب ولا كارت)، وينشر نسخة Vercel عليه.

```powershell
.\scripts\online.ps1 -Deploy
```

- اللينك بيطبع في الشاشة وبيتخزن في `.tools\last-url.txt`.
- لازم الجهاز يفضل شغال — اللينك بيموت مع العملية.
- كل تشغيل جديد بيغيّر اللينك، فاستخدم `-Deploy` عشان نسخة Vercel تاخد اللينك الجديد.
- للإيقاف: `.\scripts\stop-online.ps1`.

## تشغيل الأونلاين في الإنتاج (Render مجاني)

الأونلاين محتاج السيرفر (`packages/server`) شغال على لينك عام. الخدمة الواحدة بتقدّم الواجهة + الـ API + Socket.IO من نفس الأصل. لو الواجهة على أصل تاني (زي Vercel) السيرفر بيسمح بالأصل اللي بيطلب، والـ Auth بالتوكنز مش بالكوكيز.

1. افتح: <https://render.com/deploy?repo=https://github.com/abdobeah916-jpg/el3ab-alinzarat>
2. سجّل دخول بـ GitHub واسمح بالريبو، ثم **Apply**. الخطة `free` من `render.yaml` — بدون كارت.
3. بعد ما يخلص البيلد، الرابط (`https://<name>.onrender.com`) بيفتح اللعبة كاملة:
   - `POST /api/rooms` لإنشاء غرفة
   - `GET /api/health` للفحص
   - Socket.IO على نفس الأصل
4. لو عايز نسخة Vercel (واجهة استاتيكية) تتصل بالسيرفر ده:

```powershell
$env:VITE_API_BASE = "https://<name>.onrender.com"; pnpm deploy:vercel
```

بدون `VITE_API_BASE` نسخة Vercel بتفضل «لعب فردي» بس، لأنها واجهة من غير باك إند.

### اختبار الأونلاين من الطرفية

```bash
BASE=https://<name>.onrender.com node packages/web/scripts/online-smoke.mjs
```

السكريبت بيعمل غرفة، يضمّ لاعبين، يختار كروت، يبدأ جولة، يفتح الجرس، يضغط لاعب، يصحّح، ويتأكد إن النقط اتحدثت وإن الإجابة مش مسرّبة للاعبين.

ملاحظة: خطة Render المجانية بتنام بعد ١٥ دقيقة خمول، وأول طلب بعد النوم بياخد لحد دقيقة. الواجهة بتعمل ping مبكر عشان تصحّي السيرفر قبل ما اللاعب يدوس.

## النشر على Railway

1. أنشئ خدمة جديدة من الريبو ده واختار `Dockerfile`.
2. ضع متغيرات البيئة: `PORT=3000`، `TOKEN_SECRET=...`، `ADMIN_KEY=...`، `CORS_ORIGIN=*`.
3. انشر وجرّب: افتح الرابط من متصفحين، اعمل غرفة، وخلي لاعب ينضم بكود الغرفة.
4. لو وقع شيء، تصرف من لوجز الري modifiers كعتاد.

## قواعد سريعة

- الجرس بتوقيت السيرفر؛ أول ضغطة صح هي الأولى.
- الأصفر -1، والأحمر -3.
- شنك الحرمية -3 لهدف، كوبري يفرض التصنيف التالي، سلم وتعبان: صاحب الكرت يجاوب.
- أتوبيس: كل إجابة صح +1، وأول «أتوبيس» يقفل الجولة.
- رويال رامبل: الإجابة المكررة أو الغلط = إقصاء، والصح الفريد يبقى، والنقاط بعد الإقصاء فقط.
